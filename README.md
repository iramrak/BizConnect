# 🚀 CleanDerect CRM - AI-Powered Business Management System

Современная гибридная CRM-система, объединяющая классический реактивный интерфейс и продвинутого AI-ассистента. Разработана для автоматизации управления клиентами, сделками и задачами.

## ✨ Ключевые возможности

* **🧠 Умный AI-Ассистент:** Понимает естественный язык, умеет самостоятельно создавать задачи, сделки и связывать их с нужными клиентами из базы данных (маршрутизация намерений / Function Calling).
* **⚡ Реактивный UI (Без перезагрузок):** Использование Zustand обеспечивает мгновенное обновление таблиц, канбан-досок и дашбордов сразу после действий пользователя или ИИ.
* **🛡️ Бесперебойная безопасность:** Реализована система Silent Token Refresh с Mutex-очередью. JWT сессии обновляются незаметно для пользователя.
* **📊 Аналитический Дашборд:** Агрегация данных на стороне БД и визуализация ключевых метрик и воронки продаж.
* **🖱️ Интерактивный Канбан:** Управление сделками через Drag & Drop интерфейс с оптимистичным обновлением стейта.

## 🛠 Технологический стек

**Frontend:**
* Next.js (React 18)
* Tailwind CSS
* Zustand (State Management)
* Axios + Interceptors
* @hello-pangea/dnd (Drag & Drop)
* Recharts (Визуализация данных)

**Backend:**
* Python 3 & Django 5
* Django REST Framework (DRF)
* SimpleJWT (Аутентификация)
* OpenAI API (Интеграция ИИ)

## 🏗 Архитектурные решения

* **Intent Routing:** Бэкенд жестко валидирует JSON Schema от LLM, не позволяя нейросети "выдумывать" форматы данных.
* **Auto-linking:** При создании сделок через ИИ, бэкенд автоматически ищет клиента по имени или создает нового под капотом.
* **Optimistic UI:** Мгновенный отклик интерфейса при удалении или изменении статуса карточек.

## 🚀 Запуск проекта (Локально)

### Backend (Django)
1. Перейдите в папку проекта.
2. Создайте виртуальное окружение: `python -m venv venv`
3. Активируйте окружение: `venv\Scripts\activate` (Windows)
4. Установите зависимости: `pip install -r requirements.txt`
5. Примените миграции: `python manage.py migrate`
6. Запустите сервер: `python manage.py runserver`

### Frontend (Next.js)
1. Перейдите в папку `frontend`.
2. Установите зависимости: `npm install`
3. Создайте файл `.env.local` и добавьте ключи (API URL и т.д.).
4. Запустите сервер: `npm run dev`
